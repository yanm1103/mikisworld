# Changelog

## 1.3.0

- JARs are now named by resolution (`MikisWorld_176x144.jar`, `MikisWorld_128x128.jar`, `MikisWorld2_176x144.jar`, `MikisWorld2_128x128.jar`) and *Options > Resolution* picks the build (176x144 by default); the old names still work
- Both screen-size builds of each game now work: game 1 at 128x128 and game 2 at 176x144 (the size is read from the JAR), with the right sky, tiles, HUD and level format

## 1.2.0

- Fixed bugs
- Added extended resolution, you can now see way more map at once. Zoom in or out with `+`/`-` keys
- Added mod support and included some simple sample mods

## 1.1.0

- Fixed bugs
- Added shader options
- Added ghosting option to simulate LCD screen of Nokia phones
- Moved options in game launcher to it's own page

## 1.0.0

- First release: both games (Miki's World 1 and 2) validated against the original bytecode, gamepad and key remapping, launcher, hall of fame, bonus game.
